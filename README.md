# Multimodal Financial Distress Prediction

An AI for Finance project investigating corporate financial distress prediction for Indian companies.

## Planned Components

- Financial ratio analysis
- Annual report sentiment analysis using FinBERT
- Financial trend modelling using GRU
- Company relationship analysis using Graph Neural Networks (GNNs)
- Multimodal distress prediction
- Model explainability using SHAP
- Interactive risk dashboard

## Project Status

Initial setup and dataset research.

## Technology Stack

- Python
- Pandas and NumPy
- Scikit-learn
- PyTorch
- Hugging Face Transformers
- PyTorch Geometric
- Streamlit
